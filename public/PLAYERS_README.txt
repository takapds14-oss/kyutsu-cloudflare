KYUTSU PLAYER PHOTO / DATA RULES

1. Player data
   Edit players-data.js.
   The intended future flow is to overwrite/sync name + number from teams when a stable public source is available.

2. Player photos
   Put JPG photos in assets/players/ using the jersey number as the filename.
   Example:
     #21 -> assets/players/21.jpg
     #7  -> assets/players/7.jpg

3. Photo replacement
   Replacing 21.jpg automatically replaces the photo for player #21. No HTML editing is required.

4. Missing photos
   If no photo exists, the roster card displays the jersey number as a designed placeholder.
